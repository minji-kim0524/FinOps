- 수정 파일: `README.md`, `backend/app/auth.py`, `backend/app/main.py`, `backend/app/models.py`, `backend/tests/conftest.py`, `backend/tests/test_auth.py`, `backend/tests/test_ownership.py`, `backend/tests/test_rate_limit.py`, `e2e/tests/salary-flow.spec.js`, `frontend/src/LoginPage.jsx`, `frontend/src/LoginPage.test.jsx`

### 목적 및 이유
- 지금까지는 로그인한 상태에서만 비밀번호를 바꿀 수 있어서, 아이디/비밀번호를 모두 잊으면 계정을 복구할 방법이 없었음. 다음 작업 후보로 "DB 마이그레이션 도구 도입 / 4대보험 요율 정확도 개선 / 비밀번호 재설정 / 다른 제안" 중 비밀번호 재설정을 선택
- 프로젝트에 이메일 발송 인프라(SMTP 등)가 전혀 없는 상태라, 이메일 재설정 링크 방식은 외부 서비스 연동·API 키 관리 등 범위가 커짐. 외부 서비스 없이 바로 구현 가능한 "보안 질문/답변" 방식을 택함
- `models.py`: `User`에 `security_question`, `security_answer_hash` 컬럼 추가. 답변은 비밀번호와 동일하게 bcrypt로 해싱하되, 사용자가 답변을 입력할 때마다 대소문자/공백이 달라 실패하는 것을 막기 위해 저장·검증 전 `strip().lower()`로 정규화
- `main.py`: `RegisterInput`에 `security_question`/`security_answer` 필수 필드 추가(공백만 있는 값은 검증 실패). 신규 엔드포인트 2개 추가 — `POST /auth/security-question`(아이디로 질문 조회), `POST /auth/password-reset`(답변 검증 후 새 비밀번호로 교체). 두 엔드포인트 모두 무차별 대입 방지를 위해 기존 로그인/회원가입과 동일하게 5/minute rate limit 적용
- `LoginPage.jsx`: 회원가입 폼에 보안 질문(4개 중 선택) + 답변 입력란 추가. 로그인 화면에 "비밀번호를 잊으셨나요?" 링크를 두고, 클릭 시 아이디 입력 → 보안 질문 확인 → 답변+새 비밀번호 입력의 2단계 모달로 재설정 진행
- 테스트: 기존에 `/auth/register`를 직접 호출하던 `conftest.py`, `test_ownership.py`, `test_rate_limit.py`의 픽스처/헬퍼가 새로 필수가 된 보안 질문/답변 없이 호출해 422가 나던 것을 모두 수정. `test_auth.py`에 보안 질문 조회·비밀번호 재설정 성공/실패(오답, 존재하지 않는 아이디, 대소문자·공백 무시, 약한 새 비밀번호) 케이스를 신규 작성
- 프론트 테스트 작성 중 재설정 모달의 "보안 질문" 표시용 `Input`이 `Form.Item`에 `name` 없이 라벨만 있어 `id`/`for` 연결이 안 되는 접근성 문제를 발견 — `htmlFor`/`id`를 명시적으로 연결해 `getByLabel`로 조회 가능하도록 수정 (이전 세션에서도 동일한 유형의 antd Form id 미연결 버그를 수정한 적이 있어, 같은 패턴이 재발한 것)
- 검증: pytest 58개, 프론트엔드 테스트 8개, Playwright E2E 2개(기존 흐름 + 신규 비밀번호 재설정 흐름) 전부 통과. 브라우저에서 직접 회원가입 → 로그아웃 → 비밀번호를 잊으셨나요 클릭 → 보안 질문 확인 → 답변+새 비밀번호 입력 → 재설정 → 새 비밀번호로 로그인까지 전체 흐름을 실제로 수행해 확인
- 참고: `security_question`/`security_answer_hash`는 새로 추가된 필수 컬럼이라, 기존 로컬(`finops.db`)·Docker(`db_data`)·배포된 Render Postgres에 저장된 사용자 데이터가 있다면 스키마 불일치로 초기화가 필요함 (마이그레이션 도구 부재로 인한 동일한 제약이 반복되고 있어, 다음 작업으로 Alembic 도입을 다시 고려할 만함)
