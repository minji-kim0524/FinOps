### 목적 및 이유
- "4대보험 요율 정확도 개선 / 이력 페이지네이션 서버측 전환 / 다른 제안" 중 4대보험 요율 정확도 개선을 선택. README에 "건강보험 상/하한선 등은 반영되어 있지 않음"이라고 명시해뒀던 항목 중, 국민연금부터 우선 개선하기로 함
- 국민연금은 실제로는 세전 급여 전체가 아니라 "기준소득월액"(상/하한액으로 자른 값)에 4.5%를 곱해 계산되는데, 기존 코드는 이 상/하한선 없이 급여 전체에 요율을 곱하고 있어 고소득자·저소득자의 계산이 실제와 달랐음
- 상/하한액은 보건복지부가 매년 7월 1일 고시로 갱신하는 실제 수치라, 소득세 간이세액표 때와 마찬가지로 임의로 지어내면 위험하다고 판단. 사용자에게 "가장 최근 공식 고시 연도 기준으로 적용"하기로 확인받은 뒤, WebSearch/WebFetch로 국민연금공단 공지와 별도 요약 자료를 교차 확인해 2025.7.1~2026.6.30 적용 수치(상한액 6,370,000원, 하한액 400,000원)를 확보
- `calculator.py`: `NATIONAL_PENSION_INCOME_FLOOR`/`NATIONAL_PENSION_INCOME_CAP` 상수 추가. `gross_pay`를 이 범위로 `clip`한 값(기준소득월액)에 요율을 적용하도록 수정. 기존에 상/하한액 범위 안에 있던 급여(예: 300만원)는 계산 결과가 그대로라 회귀가 없음을 확인
- `test_calculator.py`: 상한액 초과(1000만원), 하한액 미달(30만원), 범위 내(100만원) 3가지 경계값 테스트 신규 작성
- 검증: pytest 68개 전부 통과. 브라우저에서 직접 1000만원(→국민연금 286,650원, 상한 적용), 30만원(→18,000원, 하한 적용) 급여로 계산해 API 응답까지 실측 확인
