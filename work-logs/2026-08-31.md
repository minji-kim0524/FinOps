### 목적 및 이유
- "4대보험 요율 정확도 개선 / 이력 페이지네이션 서버측 전환 / 다른 제안" 중 4대보험 요율 정확도 개선을 선택. README에 "건강보험 상/하한선 등은 반영되어 있지 않음"이라고 명시해뒀던 항목 중, 국민연금부터 우선 개선하기로 함
- 국민연금은 실제로는 세전 급여 전체가 아니라 "기준소득월액"(상/하한액으로 자른 값)에 4.5%를 곱해 계산되는데, 기존 코드는 이 상/하한선 없이 급여 전체에 요율을 곱하고 있어 고소득자·저소득자의 계산이 실제와 달랐음
- 상/하한액은 보건복지부가 매년 7월 1일 고시로 갱신하는 실제 수치라, 소득세 간이세액표 때와 마찬가지로 임의로 지어내면 위험하다고 판단. 사용자에게 "가장 최근 공식 고시 연도 기준으로 적용"하기로 확인받은 뒤, WebSearch/WebFetch로 국민연금공단 공지와 별도 요약 자료를 교차 확인해 2025.7.1~2026.6.30 적용 수치(상한액 6,370,000원, 하한액 400,000원)를 확보
- `calculator.py`: `NATIONAL_PENSION_INCOME_FLOOR`/`NATIONAL_PENSION_INCOME_CAP` 상수 추가. `gross_pay`를 이 범위로 `clip`한 값(기준소득월액)에 요율을 적용하도록 수정. 기존에 상/하한액 범위 안에 있던 급여(예: 300만원)는 계산 결과가 그대로라 회귀가 없음을 확인
- `test_calculator.py`: 상한액 초과(1000만원), 하한액 미달(30만원), 범위 내(100만원) 3가지 경계값 테스트 신규 작성
- 검증: pytest 68개 전부 통과. 브라우저에서 직접 1000만원(→국민연금 286,650원, 상한 적용), 30만원(→18,000원, 하한 적용) 급여로 계산해 API 응답까지 실측 확인

## `91a5bf8` fix. 건강보험료 상/하한액 반영 - 2026.1.1 시행 보건복지부고시 제2025-222호 기준 근로자부담분 상한액(459만1740원)/하한액(1만80원) 적용 - 국민연금과 달리 소득이 아닌 계산된 보험료 자체에 상/하한 적용, 장기요양보험료도 자동 연동 - 경계값 테스트 2건 추가 및 README 갱신

- 수정 파일: `README.md`, `backend/app/calculator.py`, `backend/tests/test_calculator.py`

### 목적 및 이유
- 앞선 국민연금 상/하한액 반영 작업에서 남겨뒀던 "건강보험 보수월액 상한선" 후속 작업. 국민연금과 이어서 바로 진행
- 건강보험은 국민연금과 근거 법령·적용 구조가 다르다는 것을 확인함: 국민연금은 "기준소득월액"(소득 자체)에 상/하한을 두지만, 건강보험은 국민건강보험법 시행령 제32조 및 '월별 건강보험료액의 상한과 하한에 관한 고시'에 따라 **계산된 보험료 금액 자체**에 상/하한을 둠. 이 차이를 놓치면 잘못된 곳에 clip을 적용하게 되므로 구현 전에 명확히 구분해야 했음
- 이 수치도 매년(또는 비정기로) 보건복지부가 고시로 갱신하는 실제 값이라, 역시 임의로 지어내지 않고 WebSearch/WebFetch로 확인. 다만 검색된 기사들이 "올해"/"내년" 같은 상대 표현을 서로 다른 기준으로 섞어 써서 연도 라벨이 실제로 어긋나 있는 것을 발견 — 고시된 총액(회사+근로자 합산)을 2로 나눈 값과 기사 속 절반 부담액 수치를 직접 대조해 산술적으로 검증한 뒤, 최종적으로 2026.1.1 시행 보건복지부고시 제2025-222호 기준 근로자 부담분 상한액 4,591,740원 / 하한액 10,080원임을 확정
- `calculator.py`: 건강보험료를 `gross_pay * 요율`로 먼저 계산한 뒤, 그 결과값 자체를 `HEALTH_INSURANCE_PREMIUM_FLOOR`/`_CAP`로 clip하도록 구현(국민연금처럼 소득을 먼저 자르는 방식과 다름을 주석으로 명시). 장기요양보험료는 기존처럼 건강보험료 컬럼을 그대로 참조해 계산되므로, 조정된 건강보험료가 자동으로 반영됨
- `test_calculator.py`: 초고소득(1.5억원, 상한 적용)·저소득(20만원, 하한 적용) 경계값 테스트 2건 신규 작성
- 검증: pytest 70개 전부 통과. 브라우저에서 직접 1.5억원(→건강보험료 4,591,740원 상한 적용, 장기요양보험 594,630원으로 연동), 20만원(→건강보험료 10,080원 하한 적용, 장기요양보험 1,305원 연동) 급여로 계산해 API 응답까지 실측 확인
