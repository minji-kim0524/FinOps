# 2026-08-16

## `a8e3aeb` test. 프론트엔드 테스트 환경 구축 - Vitest+React Testing Library 도입 - LoginPage/App 핵심 동작 테스트 7개 추가 - matchMedia/ResizeObserver jsdom 폴리필 - CI에 프론트엔드 테스트 단계 추가

- 신규 파일: `frontend/src/App.test.jsx`, `frontend/src/LoginPage.test.jsx`, `frontend/src/setupTests.js`
- 수정 파일: `frontend/vite.config.js`, `frontend/package.json`, `frontend/package-lock.json`, `.github/workflows/ci.yml`

### 목적 및 이유
- **22단계(프론트엔드 테스트 추가)** 진행: 백엔드는 pytest 30개로 촘촘히 검증되고 있었지만, 프론트엔드는 테스트가 전혀 없어서 리팩터링·기능 추가 때마다 브라우저로 수동 확인하는 것 외엔 회귀를 잡을 방법이 없었음
- Vitest + React Testing Library + jsdom 도입. `vite.config.js`에 `test` 설정(환경 jsdom, 셋업 파일) 추가, `package.json`에 `test` 스크립트 추가
- `setupTests.js`: jest-dom 매처 등록. 테스트를 돌려보다가 jsdom이 `matchMedia`(다크모드 감지용 `useTheme` 훅에서 사용)와 `ResizeObserver`(antd Table이 내부적으로 사용)를 구현하지 않아서 각각 `ReferenceError`/크래시가 나는 걸 발견 — 최소 폴리필을 셋업 파일에 추가해 해결
- `LoginPage.test.jsx`: 입력창·버튼 렌더링, 로그인/회원가입 모드 전환, 로그인 성공 시 `onLogin`이 토큰과 함께 호출되는지, 로그인 실패 시 에러 메시지가 뜨고 `onLogin`이 호출되지 않는지를 검증하는 테스트 4개 작성. `./api` 모듈을 명시적 팩토리로 모킹해 실제 네트워크 요청 없이 동작 검증
- `App.test.jsx`: 토큰이 없을 때 로그인 화면이 뜨는지, 토큰이 있을 때 메인 화면이 뜨고 `/records`·`/records/summary`를 호출하는지, 로그아웃 시 토큰이 삭제되고 로그인 화면으로 돌아가는지를 검증하는 테스트 3개 작성
- `.github/workflows/ci.yml`: 프론트엔드 job에 `npm run test`를 빌드 이전 단계로 추가해, push/PR마다 프론트엔드 테스트도 자동 실행되도록 함
- 검증: `rm -rf node_modules && npm ci`로 CI와 동일한 클린 설치 후 `test`→`build` 순서로 재현, 테스트 7개 전부 통과 및 빌드 정상 확인
