## `c20a251` style. 서비스명 제목을 상단 중앙에 더 크게 배치 - 로그인 화면은 antd Card title 대신 별도 h1으로 중앙 정렬, 로그인 후 헤더는 3분할 그리드로 제목 중앙·버튼 우측 유지 - 전역 h1 폰트 크기 확대(56→64px 등), 480px 이하에서는 세로 스택으로 가로 스크롤 방지 - vitest 48개/E2E 5개 통과

- 수정 파일: `frontend/src/App.css`, `frontend/src/LoginPage.jsx`, `frontend/src/index.css`

### 목적 및 이유
- 사용자가 AskUserQuestion 없이 직접 "서비스명인 급여 실수령액 계산기를 상단 중앙에 폰트 크기를 조금 더 키워서 배치 시켜줘"라고 요청. 코드를 바로 고치기 전에 브라우저로 로그인 화면과 로그인 후 화면을 먼저 스크린샷으로 확인해, 두 화면에서 "급여 실수령액 계산기" 문구가 서로 다른 상태였음을 파악: 로그인 화면은 antd `Card`의 `title` 속성(작고 왼쪽 정렬)으로, 로그인 후 화면은 이미 전역 `h1`(56px, 이미 큰 편이지만 헤더 안에서 왼쪽 정렬)으로 렌더링되고 있었음. `<h1>`이 앱 전체에서 로그인 후 화면 이 한 곳에서만 쓰이는 것도 grep으로 확인
- **로그인 화면**: `Card`의 `title` prop을 제거하고, 카드 바깥 위쪽에 실제 `<h1>` 태그를 새로 둬서 전역 h1 스타일(이번에 키운 큰 폰트)을 그대로 물려받게 함. `.login-page-content`라는 세로 flex 래퍼를 추가해 제목과 카드가 함께 화면 중앙에 오도록 구성
- **로그인 후 화면(`AppContent`)**: `.app-header`가 `justify-content: space-between`인 flex라 h1(왼쪽)과 버튼 그룹(오른쪽)이 양 끝에 있던 구조를, `grid-template-columns: 1fr auto 1fr` 3분할로 바꿔 h1을 가운데 칸에 둠 — 양옆 `1fr`이 남는 공간을 똑같이 나눠 가지므로 버튼 그룹이 오른쪽에 있어도 제목이 행 전체 기준으로 정확히 가운데에 옴(빈 스페이서 엘리먼트 없이 그리드 트랙만으로 해결)
- **폰트 크기**: 전역 `h1` 규칙(`index.css`)의 크기를 데스크톱 56→64px, 태블릿(1024px 이하) 36→40px, 모바일(480px 이하) 26→28px로 소폭 확대. `h1`이 로그인 후 화면 한 곳에서만 쓰이다가 이번에 로그인 화면도 실제 `<h1>`을 쓰게 되면서, 이 전역 규칙 하나만 바꿔도 두 화면에 일관되게 적용됨
- **모바일 회귀 방지**: 2주 전(2026-09-09) CSV 업로드 버튼 긴 문구 때문에 가로 스크롤이 생기던 버그를 고친 적이 있어서, 이번에도 3분할 그리드가 좁은 화면에서 같은 문제를 만들 수 있다고 보고 `@media (max-width: 480px)`에 `.app-header`를 1단 그리드로 바꿔 제목·버튼을 세로로 쌓는 규칙을 추가
- 검증: vitest 48개(기존 그대로, DOM 구조는 바뀌었지만 텍스트/역할 기반 쿼리라 영향 없음), build·oxlint 통과. 로컬 서버로 로그인 화면·로그인 후 화면을 실제 스크린샷으로 확인해 의도한 대로(제목 상단 중앙, 더 크게, 버튼은 그대로 오른쪽) 나오는지 눈으로 재확인. 모바일 뷰포트(375px)에서 `document.documentElement.scrollWidth > clientWidth`를 직접 평가해 가로 스크롤이 없음을 확인. Playwright E2E 5개(모바일 가로 스크롤 테스트 포함)도 재실행해 DOM 구조 변경에 따른 회귀가 없는지 확인
