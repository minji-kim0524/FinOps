### 목적 및 이유
- **15단계(급여 데이터 리포트/엑셀 내보내기)** 진행: 화면에서 표로 보는 것 외에, 계산 이력을 엑셀 파일로 내려받아 회사 내부 문서로 활용할 수 있게 하기 위함. pandas로 데이터를 "다루는" 것에서 "결과물로 내보내는" 것까지 확장한다는 점에서 원래 학습 목표(pandas 활용)와도 맞닿아 있음
- `main.py`: `GET /records/export` 추가. 로그인한 사용자 본인의 이력만 조회해 pandas `DataFrame`으로 만들고, 영문 컬럼명(`gross_pay` 등)을 화면에서 쓰던 것과 동일한 한글 라벨(`EXPORT_COLUMN_LABELS`)로 매핑한 뒤 `pd.ExcelWriter`(엔진: openpyxl)로 메모리 상에서 `.xlsx`를 만들어 `StreamingResponse`로 다운로드 제공. 이력이 하나도 없는 경우에도 헤더 행은 유지되도록 빈 DataFrame을 컬럼 지정해서 생성
- `requirements.txt`: pandas가 엑셀 파일을 쓰려면 필요한 `openpyxl` 드라이버 추가
- `test_export.py`: 응답으로 받은 바이트를 다시 `pandas.read_excel`로 읽어, 컬럼 순서·이름이 화면과 일치하는지, 데이터가 없을 때도 헤더는 유지되는지 검증하는 테스트 2개 추가 → 전체 23개 통과
- `frontend/App.jsx`: "엑셀로 내보내기" 버튼 추가. 다운로드에도 로그인 토큰이 필요해서, `<a href>` 직접 연결 대신 axios로 `responseType: "blob"`을 받아온 뒤 임시 `<a download>` 링크를 만들어 클릭을 트리거하는 방식으로 구현
- 검증: 브라우저에서 로그인 → 급여 계산 → "엑셀로 내보내기" 클릭까지 실제로 수행. 네트워크 탭에서 `/records/export`가 200과 함께 xlsx 바이너리(zip 기반 포맷, 약 5KB)를 정상 반환하는 것 확인, 콘솔 에러 없음
