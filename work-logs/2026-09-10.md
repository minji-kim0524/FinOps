## `1b84045` chore. 백엔드 Docker 이미지 경량화 - Dockerfile을 멀티스테이지로 전환해 venv 생성 시 딸려오는 pip/setuptools(ensurepip) 제거 - pytest/httpx를 requirements-dev.txt로 분리해 배포 이미지에서 제외(CI/README도 함께 갱신) - 실측 653MB→618MB, 컨테이너 기동 후 계산/PDF/엑셀 기능 정상 동작 확인

- 신규 파일: `backend/requirements-dev.txt`
- 수정 파일: `.github/workflows/ci.yml`, `README.md`, `backend/Dockerfile`, `backend/requirements.txt`

### 목적 및 이유
- AskUserQuestion으로 제시한 후보(백엔드 테스트 커버리지 측정, 로그인 보안 강화, Docker 이미지 크기 최적화) 중 사용자가 이 항목을 선택. `backend/Dockerfile`이 단일 스테이지로 pip 설치와 실행 환경을 한 이미지에 모두 담고 있어, 실제로 줄일 여지가 있는지 직접 측정해보기로 함
- Docker 데몬이 로컬에 떠 있지 않아 `open -a Docker`로 직접 띄우고 준비될 때까지 대기한 뒤, 기존 Dockerfile로 baseline 이미지를 빌드해 크기(653MB)와 레이어 구성을 먼저 측정. `docker history`로 뜯어보니 `pip install` 레이어 하나가 296MB로 대부분을 차지하고 있었고, `app/`에서는 전혀 쓰이지 않고 `tests/`에서만 쓰이는 `pytest`/`httpx`가 배포 이미지에 함께 설치되고 있는 게 확인됨
- **1차 시도**: 멀티스테이지로 나눠 builder 스테이지에서 venv에 설치하고 최종 스테이지엔 venv만 복사하는 전형적인 패턴을 적용하고 `requirements.txt`에서 `pytest`/`httpx`를 제거했는데, 다시 빌드해 측정해보니 654MB로 오히려 baseline과 거의 같았음(오히려 1MB 증가). 원인을 `docker history`/`du`로 직접 파봤더니, `python -m venv`가 기본으로 함께 설치하는 pip(17MB)+setuptools(11MB) ensurepip 부산물이 pytest/httpx를 뺀 만큼을 그대로 상쇄하고 있었음
- **2차 시도**: builder 스테이지에서 의존성 설치 직후 venv 안의 pip/setuptools/wheel(및 dist-info, `bin/pip*`)을 직접 삭제하도록 Dockerfile을 수정. 컨테이너 실행 시점에는 이미 만들어진 콘솔 스크립트(`alembic`, `uvicorn`)와 설치된 패키지만 있으면 되고 pip 자체는 필요 없다는 점에 착안. 재빌드해 측정하니 618MB로, baseline 대비 약 35MB(5.4%) 감소
- pip/setuptools를 지워도 실제로 안전한지(예: `pkg_resources`에 의존하는 코드가 있는지) 확신이 없어, 경량화한 이미지를 실제로 `docker run`으로 띄워 헬스체크 → 회원가입 → 상여금 포함 계산(pandas) → 급여명세서 PDF 다운로드(reportlab + 한글 폰트) → 엑셀 내보내기(openpyxl) 순서로 curl 스모크 테스트를 직접 실행해, 마이그레이션부터 전체 기능까지 문제없이 동작함을 확인
- `pytest`/`httpx`를 배포용 `requirements.txt`에서 빼면서, 테스트에 필요한 의존성은 `requirements.txt`를 상속(`-r requirements.txt`)하는 `requirements-dev.txt`로 분리. CI의 backend-tests 잡과 README의 로컬 개발 안내를 `requirements-dev.txt` 설치로 갱신(E2E 잡은 pytest를 쓰지 않아 기존 `requirements.txt` 설치 그대로 유지)
- 검증에 쓴 Docker 이미지(`finops-backend:before/after/after2/latest`)는 모두 로컬 정리 완료. 로컬 개발용 venv도 `requirements-dev.txt`로 재설치해 pytest 83개가 그대로 통과하는 것을 재확인
