### 목적 및 이유
- 5단계부터 "학습용 샘플 데이터"라고 명시해뒀던 소득세 계산을, 사용자가 직접 제공한 국세청 원본 파일(`근로소득 간이세액표_2026.03.01.xlsx`)로 교체. 데이터 정확성이 중요한 작업이라, 웹 검색으로 임의로 옮겨 적는 대신 사용자에게 공식 파일을 요청해서 진행하기로 먼저 합의함
- 원본 파일 구조 분석: 월급여 구간(770,000원 미만은 표에 없어 0으로 간주) × 부양가족 수(1~11명) 세액표(646개 구간), 월급여 1천만원 지점의 기준값, 그리고 1천만원 초과 시 적용되는 6단계 누진 계산식(소득세법 시행령 별표2)으로 구성되어 있음을 확인
- `income_tax_table.csv`: 엑셀을 직접 파싱해 `gross_pay_min, gross_pay_max, dep_1~dep_11` 형태로 재구성 (648행). 스크립트로 추출해 수작업 오타 위험을 없앰
- `tax_table.py`: 1천만원 이하는 표 조회, 초과분은 구간별 계산식(구간마다 98% 계수 적용 여부가 다름을 원본 그대로 반영)으로 분기. 별표2 4호에 따라 부양가족 11명 초과 시 "10명·11명 세액 차이만큼 계속 차감"하는 보정 공식도 구현
- **신규 기능**: 별표2 3호의 8~20세 자녀 세액공제(1명 20,830원 / 2명 45,830원 / 3명 이상 45,830원+초과 1명당 33,330원)를 반영하기로 사용자와 합의하고 `num_children_8_to_20` 필드를 계산 폼·수정 모달·CSV 업로드·엑셀 내보내기·DB 스키마 전체에 추가
- `calculator.py`: 간이세액표 조회 결과에서 자녀 세액공제를 차감(0원 미만으로는 안 내려가도록 clip)한 뒤 지방소득세(10%)를 계산하도록 순서 정리
- `test_tax_table.py`: 원본 엑셀의 실제 셀 값(1,060,000원 구간, 정확히 10,000,000원 지점, 1,770,000원 구간의 다인 가구, 4,500만원 초과 구간의 98% 계수 미적용 등)과 하나하나 대조하는 테스트 11개 신규 작성 — 이번 작업에서 가장 정확도가 중요한 부분이라 별도로 두껍게 검증
- 기존 근사치 기반 테스트들(`test_calculator.py`, `test_main.py`, `test_export.py`, `test_summary.py`)의 하드코딩된 소득세/실수령액 기대값을 전부 실제 표 기준 값으로 재계산해 갱신. `e2e/tests/salary-flow.spec.js`의 기대값도 함께 갱신
- `frontend/App.jsx`: "8~20세 자녀 수" 입력 필드와 표 컬럼 추가
- 검증: pytest 49개 전부 통과, 프론트엔드 테스트 7개 회귀 없음, E2E 테스트 통과. 브라우저에서 실제로 세전 300만원·자녀 1명 입력 시 소득세가 74,350원 → 53,520원으로 정확히 20,830원 공제되는 것을 실측 확인. README의 "예시 데이터" 문구를 실제 반영 내용으로 갱신
- 참고: `num_children_8_to_20`은 새로 추가된 필수 컬럼이라, 기존 로컬(`finops.db`)·Docker(`db_data`)·배포된 Render Postgres에 저장된 데이터가 있다면 스키마 불일치로 초기화가 필요함 (마이그레이션 도구 없이 `create_all`만 쓰고 있어 이전 스키마 변경 때와 동일한 제약)
