- 신규 패키지: `antd`, `@ant-design/icons`, `recharts`
- 수정 파일: `frontend/src/App.jsx`, `frontend/src/App.css`, `frontend/package.json`, `frontend/package-lock.json`

### 목적 및 이유
- **8단계(프론트엔드 UI 고도화)** 진행: 지금까지 순수 HTML 태그로만 만든 화면을, 실제 서비스에 가까운 UI 라이브러리로 교체
- 입력 폼: 순수 `<input>`/`<button>` → Ant Design `Form`/`Input`/`InputNumber`/`Button`으로 교체. 계산 성공/실패 시 `message.success`/`message.error` 토스트로 사용자 피드백 제공
- CSV 업로드: 기본 파일 입력 → Ant Design `Upload` 컴포넌트로 교체해 업로드 중 로딩 상태를 시각적으로 표시
- 이력 표: 단순 `<table>` → Ant Design `Table`로 교체. 컬럼별 정렬, 페이지네이션(10건 단위), 직원명 검색창을 통한 실시간 필터링 추가
- 신규: Recharts `BarChart`로 직원별 "세전 급여 vs 실수령액"을 시각적으로 비교하는 차트 추가. 검색 필터와 연동되어 필터링된 데이터만 차트에 반영
- `App.css`: antd 컴포넌트가 자체 스타일을 가지고 있어, 기존에 raw `input`/`table`/`button` 태그를 겨냥해 작성했던 커스텀 CSS가 충돌할 수 있어 제거하고 레이아웃 여백만 남김
- 검증: 브라우저에서 단건 계산(토스트 메시지 확인), CSV 일괄 업로드 후 표 반영, 직원명 검색 필터링, 컬럼 정렬, 차트 렌더링까지 실측 확인. 콘솔 에러·경고 없음
