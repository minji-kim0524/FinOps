## `599af95` style. 급여 이력 표 컬럼명 줄바꿈 문제 해결 - 컬럼별 width 지정 - scroll x를 max-content로 변경 - 헤더/셀 nowrap 처리

- 수정 파일: `frontend/src/App.jsx`, `frontend/src/App.css`

### 목적 및 이유
- 배포 후 실사용 중 발견한 UX 문제 수정: 계산 이력 표에서 "직원명~관리"까지 컬럼 헤더가 화면 크기를 키워도 계속 줄바꿈되어 가독성이 떨어짐
- 원인: `scroll={{ x: true }}`는 가로 스크롤을 "허용"만 할 뿐 컬럼 너비를 지정하지 않아서, Ant Design이 컨테이너 폭에 맞춰 컬럼을 억지로 좁히며 헤더 텍스트가 여러 줄로 쪼개졌음
- 모든 컬럼에 명시적 `width`(120~150px)를 지정하고, `scroll={{ x: true }}`를 `scroll={{ x: "max-content" }}`로 변경 — 테이블이 콘텐츠의 실제 필요 너비만큼 펼쳐지고, 넘치는 부분은 가로 스크롤로 처리되도록 함
- CSS로 `white-space: nowrap`을 헤더/셀에 추가 적용해 이중으로 줄바꿈을 막음
- 검증: 데스크톱(1280px)과 모바일(375px) 두 크기 모두에서 컬럼명·값이 한 줄로 유지되고, 넘치는 컬럼은 가로 스크롤(모바일에선 스크롤바까지 시각적으로 확인)로 볼 수 있는 것을 실측 확인
- 참고: 배포 후 변경사항이 브라우저에 바로 안 보이는 이슈가 있었는데, 하드 리프레시로 브라우저 캐시 문제였음을 확인하고 해결
