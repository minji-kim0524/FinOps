# 2026-08-11

## `bc5a7d3` feat. 다크모드 지원 추가 - antd ConfigProvider 테마 알고리즘 연동 - 우측 상단 토글 버튼 및 localStorage 테마 저장 - index.css에 수동 테마 오버라이드 추가

- 수정 파일: `frontend/src/App.jsx`, `frontend/src/App.css`, `frontend/src/index.css`

### 목적 및 이유
- **18단계(다크모드 지원)** 진행: 지금까지는 시스템이 다크 모드일 때만 일부 CSS 변수가 자동으로 바뀌는 정도였고, 사용자가 직접 선택할 방법도 없었고 antd 컴포넌트(Table, Modal, Button 등)는 전혀 반응하지 않았음
- `App.jsx`: 우측 상단에 고정된 토글 버튼(해/달 아이콘) 추가. `useTheme` 훅으로 테마 상태를 관리 — 최초 진입 시에는 시스템의 `prefers-color-scheme`을 감지해 기본값으로 쓰고, 이후 사용자가 토글하면 그 선택을 `localStorage`에 저장해 새로고침해도 유지되도록 함. antd의 `ConfigProvider`에 `theme.algorithm`(`darkAlgorithm`/`defaultAlgorithm`)을 연결해서 Table·Button·Modal·Card·Input 등 antd 컴포넌트 전체가 자동으로 다크 테마를 따르게 함
- `index.css`: 기존에는 `@media (prefers-color-scheme: dark)`로만 색상 변수가 바뀌었는데, 이러면 시스템 설정만 따라가고 사용자가 수동으로 고른 테마를 반영할 수 없었음. `:root[data-theme="dark"]` / `:root[data-theme="light"]` 명시적 오버라이드를 추가해서, 사용자가 고른 테마가 시스템 설정보다 우선하도록 함
- `App.css`: 토글 버튼을 화면 우측 상단에 고정 배치하는 스타일 추가
- 검증: 브라우저에서 로그인 화면(Segmented, Input, Card)과 로그인 후 메인 화면(입력 폼, Table, 차트, 페이지네이션, 수정 Modal)을 다크→라이트→다크로 실제 토글하며 모든 요소가 올바르게 전환되는지 확인. 새로고침해도 선택한 테마가 유지되는 것도 확인. 콘솔 에러 없음
